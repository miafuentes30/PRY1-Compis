# Casos de regresión para el Proyecto 2

Abre cualquiera de los `.cps` desde la interfaz para demostrar los cambios.
Los diez archivos `01`–`09` y `11` deben generar TAC; `10_errores_multiples.cps` no debe generarlo.
Las 25 comprobaciones estructurales automatizadas se ejecutan con `python verificar_regresiones.py` o `python verificar_proyecto.py`.
No se ejecuta el programa Compiscript; las pruebas inspeccionan las instrucciones y sus invariantes.
